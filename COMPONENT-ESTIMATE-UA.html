Покриття і наступні кроки

Ця сторінка — чернетка. Після рев’ю вирішимо, що лишаємо як канон (estimate / registry / inventory). Поки всі три артефакти співіснують.

  • Inventory — скріни по сторінках (не чіпали).
  • Registry — унікальні ID (не чіпали).
  • Estimate — D/M preview + base/delta для оцінки.
