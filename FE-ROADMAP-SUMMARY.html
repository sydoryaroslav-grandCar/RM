Роадмап міграції: фронтенд — grandcar.ua

Версія 0.1 · 14.10.2026 · чернетка на погодження. Старт робіт: понеділок 19.10.2026. Терміни для одного FE ≈ 40 год/тиждень. Це оцінка, не погоджений план: інше навантаження зсуває дати пропорційно.

Документ охоплює Next.js web-ua, UI-компоненти, збірку сторінок і підключення Public API. Бекенд і адмінка — окремий роадмап; тут бек лише як джерело контракту. UX — Telegram.

1. Коротко

Бойовий сайт grandcar.ua на новому web-ua замість WordPress: усі основні сторінки, дані з Public API, заявки, SEO-теги, потім cutover.

Робимо: UI-бібліотека + ключові URL; підключення каталогу/контенту/форм до API; uk у корені + /ru/; стенд → репетиція переїзду з беком.

Не блокує старт: до 01.11 — сторінки на моках; живі оголошення — після Public API каталогу; дату відкриття сайту тут не ставимо.

Калькулятор: екран і форма в першій хвилі FE; суми лише з бекенд API (у бек-роадмапі calc пізніше першої хвилі — узгодити строк або мок).

Висновок: праця FE 3.4–5.3 міс (низ ~14.02 / верх ~20.03.2027 від старту 19.10). У дедлайн 4–6 міс вкладаємось. Відкриття сайту — разом із готовністю беку й підписами.

3. Обсяг першої хвилі

Входить: усі головні типи сторінок з продакшену; компоненти UI + Public API; форми заявок, пошук у шапці, SEO-теги; посадкові з фільтром = /cars/ + фільтр у URL; QA / polish / участь у cutover.

Не верстка / пізніше: повна матриця legacy-URL (SEO + бек); розбір Google Search Console; деталі бек-адмінки / ingestion / міграції WP — у роадмапі беку.
