1. Коротко

Бойовий сайт grandcar.ua на новому web-ua замість WordPress: усі основні сторінки, дані з Public API, заявки, SEO-теги, потім cutover.

Робимо

  • UI-бібліотека + усі ключові URL
  • Підключення каталогу, контенту, форм до API
  • uk у корені + /ru/
  • Стенд → репетиція переїзду з беком

Не блокує старт FE

  • До 01.11 — сторінки на моках
  • Живі оголошення — після Public API каталогу
  • Дату відкриття сайту тут не ставимо
Калькулятор: екран і форма в першій хвилі FE; суми лише з бекенд API (у бек-роадмапі calc після MVP — узгодити строк або мок).
Висновок: праця FE 3.4–5.3 міс (низ ~14.02 / верх ~20.03.2027 від старту 19.10). У дедлайн 4–6 міс вкладаємось. Відкриття сайту — разом із готовністю беку й підписами.
