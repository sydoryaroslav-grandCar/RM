1. Коротко для бекенду

FE будує бойовий web-ua замість WordPress на grandcar.ua (uk корінь + /ru/). До Public API каталогу працюємо на моках; живий listing — після вашої віхи Б1 (01.11.2026).

Головне для синхрону: контракт Public API якомога раніше (Б0/Б1) → FE не блокується; далі сумісні зміни в межах v1. Заявки/контент — Б5/Б6. Cutover — разом Б7–Б9.
Дедлайн: праця FE 3.4–5.3 міс (низ ~14.02 / верх ~20.03.2027). У вікно 4–6 міс FE вкладається. Відкриття сайту — max(FE, ваш gate ~12.04, підписи).
