4. Ризики переїзду з WordPress (cutover)

Не роздувають години рядків вище, але можуть зсунути дату запуску.

  • Public API пізно або змінюється — сторінки каталогу стоять (залежність від бекенд Б1).
  • Матриця старих URL / редіректів не готова — ризик SEO після вимкнення WP (робота SEO+бекенд, не лише FE).
  • Немає staging / домену в день перемикання — cutover переноситься.
  • Перший тиждень після запуску — гасіння багів (частина шару D).
Cutover = новий сайт уже бойовий на своєму середовищі → перемикаємо домен / трафік зі старого WordPress. Не «друга хвиля фіч», а фінал релізу.
