10. Як читати естімейти

Чернетка для roadmap. Не фінальний контракт.

  • Не множити на кількість сторінок: BonusLeadForm = один рядок, integration в layout ≈ 0.5–1 год / сторінка.
  • Варіант (saved / blog pagination first-last) — частка від базової, уже закладена в діапазон.
  • Buffer на design tokens, a11y, i18n keys, QA: +15–25% зверху суми.
  • Page inventory зі скрінами: FE-COMPONENTS-UA.html (якорі не чіпаємо).
  • Детальна оцінка з D/M preview і delta: COMPONENT-ESTIMATE-UA.html.
